# Lauf-Tracker

Das Kursprojekt: ein Konsolenprogramm, das Läufe erfasst und auswertet.
Es wächst mit jedem Modul, von einem Pace-Rechner bis zu einem Lauftagebuch, das als CSV speichert.

Stand und Etappen: siehe [README im Hauptordner](../README.md#kursprojekt-lauf-tracker).
